## Colour

These tables are generated from `guidelines/link/link.spec.yaml`. Each row is checked three ways:

- **Dark value (spec):** the colour the design specifies, resolved from `src/theme/tokens.jsonc`.
- **Token check:** whether the named semantic token exists and holds that colour.
- **Rendered:** the colour the real component draws in that state, measured in this page.
